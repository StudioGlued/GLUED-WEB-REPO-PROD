Frame

Five second loop at 30fps. MP4 is H.264, no alpha. MOV α is QuickTime Animation, 32-bit with straight alpha — lossless, and macOS plays it natively. It is a chunky codec: roughly 120MB for a 1080×1350 loop and around 700MB at 4K. PNG α writes a numbered sequence in a zip, which is smaller and imports everywhere, but is not a movie file.
